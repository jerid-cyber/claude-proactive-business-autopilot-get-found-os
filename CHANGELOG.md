- Reference files: Business Brain template, 100-skill routing catalog, Visibility Score rubric.
- CONNECTORS.md mapping recommended connectors to agents with no-connector fallbacks.
- GitHub marketplace manifest, CI validation, automatic `.plugin` release packaging.
